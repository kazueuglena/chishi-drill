# 地誌ドリル — 地理探究 一問一答 + 間隔反復

高校地理探究の**地誌（現代世界の諸地域）全12地域 + 系統地理、合計2528問**を、
間隔反復（SRS）で回すための単一HTMLアプリ。

インストール不要。スマホのホーム画面に追加すればアプリのように使える。
進捗はブラウザに保存されるのでオフラインでも動く。

出題元は4種類で、範囲選択で切り替えられる。

全問に1〜2文の解説つき。難易度は 基礎／標準／発展 の3段階でタグづけしてある。

## 機能

英単語アプリ（mikan・ターゲットの友など）の導線に寄せて、**単元をタップしたらすぐ演習が始まる**作りにしてある。

### 単元タブ — ここが主導線
- 地域を開くと**章（単元）がカードで並ぶ**。各カードに **問題数・出題元・習得率・進捗バー**が出る
- カードをタップするとその章だけの演習が始まる。「この地域をまとめて」で地域一括も可
- 上部の絞り込みは**常時表示**で、切り替えると単元カードの問題数がその場で変わる
  - **重要度**: 基礎 1347 / 標準 889 / 発展 292
  - **出題元**: 一問一答 719 / 授業プリント 99 / 教科書 487 / 補充 1223
- 該当0になった単元はグレーアウトする。100%の単元は枠が緑になる

### 学習
- **めくる**（フラッシュカード＋4段階の自己評価）と **4択**をヘッダーで切り替え
  - 4択の誤答は同じ章 → 同じ地域の順に集めるので、勘で当たりにくい
  - 4択は正解＝「わかる」、不正解＝「もう一度」として自動でSRSに記録される
- **1セットの枚数**もヘッダーで 20 / 50 / 100 / 全部 を切り替え
- 出題順は「今日が復習期限の札 → 未学習 → その他」。「もう一度」の札は同じセッション中に再登場
- SM-2 を簡略化した間隔反復。連続正解で 1日 → 3日 → …と間隔が伸び、間違えると 0 に戻る

### そのほか
- **続きから** — 直近にやった単元をホームから1タップで再開
- **苦手だけ** — 間違えた回数の多い順に出題
- **一覧・検索** — 全問を通し読み。答えはぼかし表示で、タップで開く。絞り込みが効く
- **記録** — 連続学習日数、累計枚数、間違えやすい問題の上位30件
- **バックアップ** — 進捗をJSONで書き出し／読み込み

### キーボード操作

左手を **A S D F** のホームポジションに置いたまま完結する。

| キー | 動作 |
|---|---|
| `Space` / `J` / `Enter` | めくる（4択では採点後に次へ） |
| `A` | もう一度（忘れた） |
| `S` | あやふや（迷った） |
| `D` | わかる（正解） |
| `F` | かんぺき（即答） |
| `Esc` | 中断 |

4択モードでは `A`〜`F` がそのまま選択肢1〜4になる。`1`〜`4` も従来どおり使える。
伏せたまま `A`〜`F` を押すと、まずカードがめくれる（見ずに評価してしまう事故を防ぐため）。

## 構成

```
index.html          ← 配布物。データを埋め込んだ単一ファイル（自動生成）
data/qa.json        ← 問題データ（ここが原本）
src/template.html   ← アプリ本体のテンプレート
tools/build.py      ← data/qa.json を template に埋め込んで index.html を作る
```

問題を足したり直したりするときは `data/qa.json` を編集して、

```bash
python3 tools/build.py
```

を実行すると `index.html` が作り直される。ビルドツールもパッケージも要らない。

### データ形式

```json
{
  "regions": [{
    "code": "cn", "name": "中国",
    "sections": [{
      "title": "経済の改革開放による変化",
      "src": "school",
      "items": [{
        "id": "cn0001",
        "q": "…何とよばれているか。",
        "a": "世界の工場",
        "alt": [],
        "note": "解説…",
        "level": 1,
        "src": "school"
      }]
    }]
  }]
}
```

`level` は 1=基礎 / 2=標準 / 3=発展、`src` は `school`（学校の一問一答）/ `print`（授業プリント、`print_no` 付き）/ `tb`（教科書、`page` 付き）/ `ext`（補充）。

## 作り方（再現手順）

1. 学校配布の「８月小テスト一問一答.pdf」を左右カラムに分けて `pdftotext -layout` で抽出 → 151問を構造化
2. 6月の授業プリント由来の一問一答HTML2種をパース・重複排除 → 系統地理515問
3. 教科書「地誌編」p.426〜601（スキャンPDF）を 200dpi で画像化 → tesseract(jpn) でOCR
   → 章ごとに既存問題と突き合わせて不足事項を抽出 → 489問
4. 各地域の網羅用問題を作成 → 1254問
5. 解答の重複・設問形式・解説の有無を機械チェックしてマージ

## 注記

- 学校配布プリント・教科書由来の問題は個人の学習用であり、再配布を意図したものではない。
- 教科書由来の問題はOCRを介しているため、細部の表記が原文と異なる場合がある。参照ページを頼りに原本で確認できる。
- 補充分は地理探究の標準的な内容から作成したもので、統計の順位や数値は変動するため断定を避けた表現にしてある。
- 進捗は `localStorage` に保存される。ブラウザの履歴消去で消えるので、大事な記録はバックアップを取ること。
